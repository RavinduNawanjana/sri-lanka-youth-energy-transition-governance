# Planned, requested, reported and verified are distinct states

The 2026–2030 chapter roadmap is written mainly in the future tense and includes quarterly campaigns, training, collaboration and policy labs. The national-workshops proposal requests support for four workshops. The technical-committee request, dated 10 February 2026 in the source, says the four workshops have been completed. These two documentary statements are in unresolved tension without dated independent proof. The register **does not resolve the conflict** by preferring either account.

- `proposed`: author-described intention in a roadmap.
- `funding_requested`: resources sought, not necessarily awarded.
- `scheduled_unverified`: possible schedule; proof of implementation absent.
- `implementation_reported_unverified`: narrative claims completion but primary documentation not checked.
- `completed_verified`: dated primary source and evidence locator have been inspected by a reviewer. Software checks schema presence only, not real-world validity.

**Outcome measurement plan:** knowledge pre/post assessments need ethics/consent; use matched respondent identifier with privacy review, confidence intervals conditional on sampling assumptions, attrition accounting and pre-specified endpoints. This repo deliberately does not invent attendee records or learning gains to create regression tables.
