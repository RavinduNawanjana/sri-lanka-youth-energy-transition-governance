# Model card

| Characteristic | Value |
|---|---|
| Purpose | R-based workplan registry, evidence gates, quarterly monitoring and reporting |
| Type | Transparent screening / analytic demonstration |
| Evidence | Author draft(s), listed in `SOURCE_REGISTER.md`, plus referenced standards where appropriate |
| Input status | Deliberately synthetic and visibly labelled illustrative |
| Intended use | Expose assumptions, units, modelling structure, sensitivity and missing evidence |
| Prohibited interpretation | Certification, regulatory compliance, actual emissions/removals, real project economics or completed delivery |
| Required human review | Sector specialist, data owner, relevant regulatory/verification authority |
